# AI-Powered Business Intelligence Analyst

## 📌 Project Overview

This project is an **AI-Powered Business Intelligence Analyst** developed to analyze Amazon sales data and generate meaningful business insights.

The project combines **Python, Power BI, DAX, and Gemini AI** to perform data cleaning, validation, exploratory analysis, business intelligence reporting, AI-powered analysis, and result validation.

## 🎯 Objectives

* Analyze Amazon sales performance
* Calculate important business KPIs
* Identify top-performing products, brands, and categories
* Analyze revenue trends
* Understand customer and geographic patterns
* Build an interactive Power BI dashboard
* Integrate Gemini AI for business analysis
* Validate AI-generated numerical results against the underlying dataset

## 🤖 AI-Powered Business Intelligence

The project integrates **Gemini AI** to provide business-oriented analysis based on the Amazon sales dataset.

The AI analyst can use predefined analytical functions to obtain data-driven results and provide business insights and recommendations.

### AI Answer Validation

A key feature of the project is **AI result validation**.

Instead of blindly trusting AI-generated numerical answers, analytical results are compared with calculations performed directly on the cleaned dataset.

This helps reduce incorrect numerical responses and improves the reliability of AI-assisted business analysis.

## ▶️ How to Run

### Python Analysis

1. Open `Amazon.ipynb` using **Jupyter Notebook** or **Google Colab**.
2. Load the Amazon sales dataset.
3. Configure the Gemini API key using secure secret storage.
4. Run the notebook cells sequentially.

### Power BI Dashboard

1. Open `Amazon_Sales_Dashboard.pbix` using **Power BI Desktop**.
2. Refresh the data if required.
3. Explore the three dashboard pages and interact with the available filters.
